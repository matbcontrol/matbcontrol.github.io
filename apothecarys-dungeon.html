// Rendering

Grass for large environments

The grass is drawn with GPU instancing through DrawMeshInstancedIndirect and loads in chunks. The blades move with vertex animation in the shader, driven by the shared wind include.

// Tech Art · Shaders

One wind core for all vegetation

A single include, WindCore.hlsl, drives the grass, the flowers and every other object that sways. Layered value noise (FBM) makes the steady breeze. A travelling gust wave adds bursts on top of it.

Each vertex bends with the wind and then sags, which keeps a blade from stretching. The include depends only on _Time.

  • HLSL
  • Value noise + FBM
  • Gust waves
  • Per-vertex bend
  • Distance fade
  • GPU instancing
