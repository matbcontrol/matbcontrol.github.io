Cyber Abyss is an online action game. I worked on it as a freelance Unity developer and built the client-server side, including the progression and microtransaction systems.

// Architecture

The client-server side

I set up the architecture so that new online features can be added to it later.

// Progression · Shop

Progression and microtransactions

Both systems are part of the client-server work. The recording shows them in the game: a deck of ten heroes, supply cases with hero drop chances, a black market with timed offers paid in credits, the tower hub and a squad battle.

// Yandex Games

A Yandex Games build

The same codebase has a Yandex Games build with payments, rewarded ads and cloud saves.

// Web3 · Base

A Web3 build for Base and Farcaster

The codebase also ships as a Web3 build for Base and Farcaster, with wallet sign-in through ethers.js, a Solidity contract and a bridge from JavaScript to Unity.
